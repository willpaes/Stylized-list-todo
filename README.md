# Stylized-list-todo ✨

## Description

This project demonstrates the creation of a styled to-do list using HTML and CSS.

It includes:

- Checkbox-based task items
- Nested sub-items with external links
- Custom link styling using CSS pseudo-classes
- Basic accessibility practices with labels and focus states

The project is designed to help beginners understand how to structure lists, associate labels with form elements, and create interactive link effects using CSS.

## Learning Objective 🎯

By the end of this example, you will be able to:

- Create structured to-do lists using HTML.
- Use checkboxes to represent task completion.
- Build nested lists for organizing related content.
- Style hyperlinks with CSS pseudo-classes.
- Understand the difference between:
  - link;
  - visited;
  - hover
  - active;
  - focus.
- Improve accessibility using labels and keyboard focus indicators.

💡 This project is ideal for beginners learning HTML5, CSS3, and web accessibility fundamentals.
